# Nova AI — Puter.js

Responsive AI chat app powered by Puter.js.

Features:
- Streaming AI responses
- Multiple chats with browser persistence
- Chat search
- Model selector
- Dark/light theme
- Mobile responsive layout

Run locally with `python -m http.server 5500`, then open http://localhost:5500.

Deploy as a static site on Vercel, Netlify, or GitHub Pages.
